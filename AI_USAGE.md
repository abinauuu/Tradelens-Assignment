# AI usage

Used AI for :-

* **Code structure:** Helped plan how to separate data ingestion, parsing, analytics, rule checks, and report generation.
* **Data parsing:** Helped understand how to handle MT5 CSV files, broker Excel files, dates, and numeric values.
* **Debugging:** Used AI to investigate errors and improve the code based on test results.
* **Documentation:** Used AI to help draft the README and organize project documentation.
